# 🌸 NekoSales Analytics - Anime Sales Dashboard & Slide Manager ✨

ระบบวิเคราะห์ยอดขายและจัดการสไลด์นำเสนอสไตล์อนิเมะคาวาอี้ สำหรับแสดงผลผ่าน **GitHub Pages**

## 🌟 คุณสมบัติเด่น (Features)

1. **🗑️ คัดกรองหมวดหมู่ "ขยะเปียก" (Outlier Data Cleansing)**
   - วิเคราะห์การกระจายตัวของอายุลูกค้า (Mean = 32.19 ปี, SD = 10.02 ปี)
   - คัดแยกข้อมูลที่อายุมากกว่าเกณฑ์ปกติ (`Mean + 2SD > 52.2 ปี` คือกลุ่มอายุ 53-63 ปี) จำนวน **179 รายการ** ออกไปอยู่ในหมวดหมู่ **"ขยะเปียก"** อย่างชัดเจน
   - มีตารางตรวจสอบ ค้นหา และส่งออกเป็นไฟล์ CSV ได้ทันที

2. **📑 ตัวจัดการสไลด์ทั้งหมด (Slide Deck Presentation)**
   - นำเสนอสไลด์ 7 สไลด์ พร้อมปุ่มเลื่อนหน้า สารบัญสไลด์ และคีย์ลัดลูกศรซ้าย/ขวา
   - กราฟแบ่งหมวดหมู่ชัดเจนพร้อมการ์ดคำอธิบายวิเคราะห์เชิงลึกจากมาสคอตอะนิเมะ:
     - **Slide 1**: Executive Summary & สัดส่วนยอดขาย 5 ภูมิภาค
     - **Slide 2**: การคัดกรองข้อมูล & หมวดหมู่ขยะเปียก (Outliers)
     - **Slide 3**: Top 10 จังหวัดยอดขายสูงสุด & ยอดเฉลี่ยต่อบิล (AOV)
     - **Slide 4**: ประสิทธิภาพหมวดหมู่สินค้า 7 หมวด & สินค้าขายดี
     - **Slide 5**: ช่องทางการจัดจำหน่าย & พฤติกรรมการชำระเงิน
     - **Slide 6**: ข้อมูลประชากรศาสตร์ & ช่วงอายุลูกค้า
     - **Slide 7**: การจัดส่ง, อัตราสำเร็จคำสั่งซื้อ & รีวิวความพึงพอใจ

3. **🗺️ ระบบ UI แยกหมวดหมู่ตามภาค & จังหวัด**
   - **Region Button Group**: ปุ่มกดเลือกดูตามภาค (ภาคกลาง, ภาคเหนือ, ภาคอีสาน, ภาคตะวันออก, ภาคใต้, หรือทั้งหมด)
   - **Province List Selector**: รายการเลือกดูเจาะลึก 25 จังหวัด พร้อมชิปปุ่มกดด่วน
   - แสดง KPIs รายจังหวัด, ยอดขายตามหมวดหมู่, ช่องทางการขาย, วิธีชำระเงิน และ 5 สินค้าขายดีประจำจังหวัด

4. **🌸 ความน่ารักสไตล์อนิเมะ (Anime Aesthetic)**
   - โทนสีพาสเทลซากุระ สดใส สบายตา
   - กลีบซากุระร่วงแบบ Canvas Animation (สามารถเปิด/ปิดได้)
   - เสียงเอฟเฟกต์คาวาอี้สังเคราะห์ด้วย Web Audio API (สามารถเปิด/ปิดได้)
   - มาสคอตชิบิและกล่องคำแนะนำสุดน่ารัก

## 🚀 วิธีเปิดใช้งานบน GitHub Pages (Deployment Guide)

1. **สร้าง Repository บน GitHub:**
   - ไปที่ [GitHub](https://github.com) แล้วกด **New repository**
   - ตั้งชื่อ เช่น `anime-sales-dashboard`
   
2. **Push โค้ดขึ้น GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: complete anime sales dashboard & slide manager"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```

3. **เปิดใช้งาน GitHub Pages:**
   - ไปที่แท็บ **Settings** ของ Repository
   - เมนูด้านซ้ายเลือก **Pages**
   - ตรงหัวข้อ **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   - รอ 1-2 นาที คุณจะได้ URL เช่น:
     `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`

สามารถเปิดดูได้ทั้งบนคอมพิวเตอร์และมือถือแบบ Responsive 100%!
